# Online Learning Enrollment Analytics Platform

Data Engineering Project using Databricks, SQL, and Lakeflow Spark Declarative Pipelines.

## Project Overview

This project implements Medallion Architecture (Bronze, Silver, Gold) to clean and analyze online course enrollment data.

## Technologies Used
- Databricks
- SQL
- Lakeflow Spark Declarative Pipelines
- Unity Catalog
- Databricks AI/BI Dashboard
